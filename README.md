## Cloud Agent Delegation Demo

This repository contains a demonstration of cloud agent delegation and change approval concepts.

### Files

- `2.py` - Python script demonstrating cloud agent delegation functionality

### Usage

Run the demo:
```bash
python3 2.py
```

### Features

- **Change Approval**: Approve changes through the cloud agent
- **Task Delegation**: Delegate tasks to the cloud agent for processing
- **Bilingual Support**: Supports both English and Chinese (中文) messages
